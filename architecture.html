Factory Inventory Management System

System architecture, technology stack, and request lifecycle for the Vue 3 + FastAPI demo application.

Technology Stack

Frontend

  • Vue 3 with Composition API
  • Vite dev server and bundler
  • Axios HTTP client
  • Custom SVG charts, CSS Grid
  • Port 3000

Backend

  • Python 3 with FastAPI
  • Pydantic response models
  • Uvicorn ASGI server
  • Auto-generated OpenAPI docs
  • Port 8001

Data Layer

  • JSON fixtures in server/data/
  • Loaded into memory at startup
  • No database, no persistence
  • mock_data.py handles I/O
  • generate_data.py seeds files

Request Lifecycle (Data Flow)

  1. User changes a filter
    FilterBar.vue updates one of four shared refs in useFilters: time period, warehouse, category, or order status.
  2. View reacts and calls the API client
    A watch on the filter refs fires the view's loadData(), which calls a function in api.js with getCurrentFilters().
  3. api.js builds the request
    Active filters (anything not "all") are appended as query-string params and sent via axios to http://localhost:8001/api/....
  4. FastAPI route filters in memory
    main.py reads the relevant list from mock_data.py, applies Python list comprehensions matching the query params, and returns the subset.
  5. Pydantic validates the response
    Each item is coerced through its response_model (e.g. InventoryItem, Order) so the JSON shape is guaranteed.
  6. View stores raw data, computed derives the rest
    The response lands in a ref (e.g. allOrders); charts, totals, and tables are computed properties that recalculate automatically and re-render the SVG/Grid UI.
